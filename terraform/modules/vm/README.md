# Terraform module: vm

Универсальный модуль для создания VM в Proxmox путём клонирования шаблона.
Поддерживает Astra Linux и Ubuntu.

## Что делает модуль

1. Клонирует указанный шаблон (полный клон — диск независим от шаблона).
2. Настраивает CPU, RAM, сетевой интерфейс, qemu-guest-agent.
3. Через cloud-init: задаёт статический IP, hostname, пользователя и SSH-ключ.
4. Запускает VM.
5. Диск: по умолчанию **наследуется от шаблона**; при заданном `disk_size` — **увеличивается** (см. раздел «Диск»).

## Использование

```hcl
module "app_01" {
  source = "../../modules/vm"

  vm_name        = "app-01"
  target_node    = "proxmox"
  template_id    = 101
  ip_address     = "172.16.0.211/24"
  ssh_public_key = var.ssh_public_key
  tags           = ["app", "astra"]

  # Необязательно: увеличить диск до 40 GiB (по умолчанию — как в шаблоне)
  # disk_size    = 40
  # disk_storage = "local-lvm"
}
```

## Диск (`disk_size`)

По умолчанию диск **наследуется от шаблона** (`disk_size = null`). Параметр задавайте
**только для увеличения** — Proxmox не умеет уменьшать размер диска.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `disk_size` | `null` | Размер диска, GiB. `null` = как в шаблоне |
| `disk_storage` | `local-lvm` | Datastore для диска |
| `disk_interface` | `sata0` | Интерфейс диска (должен совпадать с шаблоном) |
| `disk_discard` | `on` | Проброс discard/trim |
| `disk_ssd` | `true` | Эмуляция SSD |
| `disk_iothread` | `true` | Отдельный I/O-поток |

> ⚠️ **Почему `dynamic "disk"`, а не статичный блок.**
> При клоне провайдер применяет **дефолты схемы** к любым неуказанным атрибутам диска
> (`size=8`, `discard=ignore`, `ssd=false`, `iothread=false`) и **перезаписывает** ими
> настройки шаблона. Поэтому блок включается только при заданном `disk_size`, а остальные
> атрибуты дублируются явно (иначе — регресс). Иначе (`size=20` по умолчанию) Terraform
> пытался бы **сжать** диск с 32 GiB — Proxmox так не умеет.
